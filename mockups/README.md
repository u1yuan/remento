# Remento recap mockups

Eight portrait mockups for the Codex x UIAI Hackathon recap flow. These are illustrative UI images, not edits to the app source.

| File | Screen |
| --- | --- |
| `01-event-cover.png` | Event cover and recap opening |
| `02-arrival.png` | Arrival and event atmosphere |
| `03-activity.png` | Saved activity photo |
| `04-memory.png` | Private person memory |
| `05-connection.png` | Confirmed reconnection, kept private |
| `06-missing-moments.png` | Gentle partial-participation treatment |
| `07-participant-type.png` | All-Rounder reveal, with its saved categories shown |
| `08-export-summary.png` | Shareable summary preview and privacy cue |

All personal content is sample data. The participant type is based on saved categories: Scene Catcher for activity photos only, Detail Keeper for a person memory only, Connector for a confirmed connection only, and All-Rounder for any two or more categories. The current type screen demonstrates the All-Rounder case; counts do not affect the type.

The export summary omits attendee names, personal notes, profile links, and QR data. It includes event metadata and a generic activity image, and says that connections and personal notes stay on the device.

The visual direction uses vivid cobalt, coral, lime, warm paper, oversized editorial type, and scrapbook collage cues inspired by the supplied `sample.png`; it does not use Spotify branding or layouts. Rendered through Stitch because the built-in image generation tool was unavailable in this session.
