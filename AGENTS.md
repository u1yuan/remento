# Context

You are in the Codex x UIAI Hackathon. I want our build to be fun, grounded on research, and solves a real problem. Update this file as the project evolves.

## Fast problem search

- Start with a specific problem fellow students experience, then check evidence and existing solutions before proposing features. For a cross-domain idea, name the two domains and the specific moment where they meet.
- Timebox each research pass to about 25 minutes: 5 minutes for candidate problems, 10 minutes for sources and alternatives, and 10 minutes to compare them. Record the result in `RESEARCH.md`.
- For each candidate, identify the current workaround, a plausible gap, and a small demo. Search for the nearest existing product, including one that already combines the domains. Label assumptions that have not been checked with classmates.
- Keep the selection open while ideating. After the user chooses a problem, build its first prototype slice and use classmate feedback to refine it.
- When a specific library, framework, SDK, API, CLI, or cloud service enters the build, use Context7 for current documentation before answering setup or usage questions.
